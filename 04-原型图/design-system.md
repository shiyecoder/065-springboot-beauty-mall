# 设计系统 · 美妆护肤商城与试用装派发系统

## 1. 视觉方向

轻奢美妆风格：低饱和紫为主色，前台以大图与留白为主，报告页强调评分与图片，
后台沿用同一主色做紧凑表格布局。状态不只用颜色表达，必须同时出现中文标签。

## 2. 色彩

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 | `#7A5AA6` | 顶栏、主按钮、当前菜单、关键数字 |
| 主色深 | `#63458A` | 主按钮 hover |
| 主色浅 | `#F3EEF9` | 选中行、主色底 |
| 辅助色 | `#A98BC9` | 次级按钮、筛选选中、普通图表系列 |
| 强调色 | `#E0B36A` | 重点提示、待办数量、对比系列 |
| 页面背景 | `#F5F6F7` | 内容区背景，容器用白色 |
| 正文 | `#1F2933` | 标题与正文 |
| 次要文字 | `#5B6770` | 说明、表头 |
| 弱化文字 | `#98A2AB` | 提示、时间戳 |
| 分割线 | `#E3E6E8` | 卡片、表格边线 |
| 成功 | `#2B7955` | 已完成、已通过 |
| 危险 | `#B02A37` | 驳回、超时、删除（小面积） |

图表配色从主色/辅助色/强调色/中性灰派生，同一含义跨页面一致：
系列一 `#7A5AA6`、系列二 `#A98BC9`、系列三 `#E0B36A`、系列四 `#8FA3B0`、系列五 `#C9CFD4`。

## 3. 字体阶梯

| 层级 | 字号 | 字重 | 用途 |
|---|---|---|---|
| H1 | 27-38px | 700 | 登录主标题、门户首屏 |
| H2 | 15px | 600 | 页面区块标题（sec-h） |
| H3 | 13.5px | 600 | 卡片标题 |
| 正文 | 13px | 400 | 表格、表单 |
| 辅助 | 12px | 400 | 说明文字 |
| 弱化 | 10.5-11px | 400 | 时间、tip |
| 数字 | 18-26px | 700 | KPI 关键数字（tabular-nums） |

字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", Helvetica, Arial, sans-serif`。

## 4. 圆角与阴影

- 圆角：卡片/容器 8px，按钮 6px，标签 11px 胶囊，输入框 6px，门户卡片 10-14px
- 阴影：`0 1px 2px rgba(31,41,51,.06), 0 2px 8px rgba(31,41,51,.04)`
- 分割：卡片 1px `#E3E6E8` 描边，不叠加多重阴影

## 5. 布局

- 后台：220px 左侧菜单 + 56px 顶栏 + 自适应内容区，内容区外边距 24px
- 门户：56px 顶部导航 + 最大宽度 1240px 内容居中
- 看板首页：8 项 KPI 单行 + 6 个图表两行三列，1440×900 一屏无滚动
- 表单：标签宽 86-100px，单列输入 360-520px，搜索下拉 180-240px

## 6. 状态语义

申领：待审核(warn) / 已驳回(bad) / 待发放(info) / 已发放(info) / 待提交报告(warn) / 已完成(ok)
商品：待上架(n) / 在售(ok) / 已售罄(bad) / 已下架(n)
试用装：待上架(n) / 可派发(ok) / 已派完(bad) / 已过期(n) / 已下架(n)
订单：待支付(warn) / 待发货(info) / 已发货(info) / 已完成(ok) / 已退款(bad) / 已取消(n)
报告：待审核(warn) / 已通过(ok) / 已驳回(bad) / 已隐藏(n)
转化：高意向(ok) / 中意向(warn) / 低意向(n) / 待评估(info)

## 7. 角色与视觉区分

| 角色 | 入口 | 视觉 |
|---|---|---|
| 试用用户 | 门户（浅底大图、卡片流） | 紫色渐变 hero，白卡 + 圆角按钮 |
| 品牌运营 | 后台（侧栏 + 表格） | 主色顶栏，密集表格 |
| 内容审核员 | 后台 | 同后台，报告卡片重点展示评分 |
| 客服专员 | 后台 | 转化等级三栏色卡 |
| 数据分析员 | 后台 | 图表优先，规则版本卡 |
| 系统管理员 | 后台 | 系统管理分组 |
